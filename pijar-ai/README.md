# Pijar HTML Slides

Static HTML version of the Pijar audience variant.

## Local Preview

Open `pijar-slides.html` directly in a browser, or run a static server from this folder:

```bash
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173/pijar-slides.html
```

## Deploy with Vercel

Set the Vercel project root/output directory to this folder:

```text
agentic-ai-workplace/html
```

No build command is required.

## Navigation

- Right arrow / Space: next slide
- Left arrow: previous slide
- O: overview
- F: fullscreen
- H or ?: help
