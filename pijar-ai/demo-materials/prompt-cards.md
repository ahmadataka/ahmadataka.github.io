# Prompt Cards - Pijar Variant

## Prompt 1 - Program Brief Mingguan

```text
Goal: Buat program brief mingguan untuk pimpinan dari update mentah dan data kegiatan.

Context:
- Baca 01-program-update-raw.md.
- Baca 03-program-activities.csv.
- Baca 04-program-indicators.md.

Constraints:
- Bahasa Indonesia ringkas dan siap dibaca pimpinan.
- Jangan mengarang angka, approval, MoU, atau komitmen mitra.
- Bedakan registered, attended, dan data yang masih sementara.
- Tandai semua data yang perlu dikonfirmasi.

Done when:
- Buat file demo-output/program-brief-mingguan.md.
- Sertakan executive brief, capaian, risiko, 5 prioritas minggu ini, owner yang perlu ditentukan, dan checklist review manusia.
```

## Prompt 2 - Partner Email Action Summary

```text
Goal: Ubah email panjang mitra menjadi action summary dan draft response.

Context:
- Baca 02-partner-email.md.
- Baca 04-program-indicators.md.

Constraints:
- Jangan menjanjikan hal yang belum diputuskan.
- Tandai deadline, kebutuhan data, dan risiko komunikasi.
- Draft response harus sopan, ringkas, dan kolaboratif.

Done when:
- Buat file demo-output/partner-action-summary.md.
- Sertakan action items, data yang harus disiapkan, draft balasan email, dan pertanyaan klarifikasi.
```

## Prompt 3 - Policy/Partner Brief Helper

```text
Goal: Buat outline one-page partnership brief yang menghubungkan Future Talent dan Future Planet.

Context:
- Baca semua file di folder ini kecuali README.md, AGENTS.md, dan prompt-cards.md.

Constraints:
- Jangan membuat klaim dampak berlebihan.
- Jangan menyebut insight lapangan sebagai rekomendasi kebijakan final.
- Tandai bagian yang belum punya bukti.
- Output harus cocok untuk diskusi awal mitra.

Done when:
- Buat file demo-output/one-page-partnership-brief-outline.md.
- Sertakan narasi utama, struktur 1 halaman, data pendukung, risiko, dan checklist approval sebelum dikirim.
```
