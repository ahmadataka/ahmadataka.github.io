# Demo Materials - Pijar Variant

Data di folder ini fiktif, tetapi dibuat agar dekat dengan konteks kerja Pijar: program Future Talent/Future Planet, koordinasi mitra, policy/research, dan komunikasi dampak.

## File

- `01-program-update-raw.md`: update program mentah dari beberapa workstream.
- `02-partner-email.md`: email panjang dari calon mitra.
- `03-program-activities.csv`: data kegiatan program.
- `04-program-indicators.md`: indikator dan prinsip pelaporan.
- `prompt-cards.md`: prompt siap pakai untuk demo Codex.
- `demo-output/`: folder output demo.

## Demo Cepat

1. Gunakan Prompt 1 untuk membuat program brief mingguan.
2. Gunakan Prompt 2 untuk membuat action summary dari email mitra.
3. Gunakan Prompt 3 untuk membuat policy/partner brief helper lintas file.
